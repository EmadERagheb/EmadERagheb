## ✦ About me

I build **scalable, containerized back-ends** with **Clean Architecture and CQRS**, and the **AWS infrastructure** they run on, written as code with **Terraform**.

- 🏦 **Now:** Senior Software & Cloud Engineer at **Sanaddak**, a gold-backed fintech, where I lead the platform revamp: eKYC, payments and the full move to **AWS ECS Fargate + MongoDB Atlas**
- 📈 **Before that:** built the **Government Fixed Income Trading** back-end at the **Egyptian Exchange (EGX)** with .NET 8, MediatR, Oracle, Redis and SignalR
- 🔐 I care about **security and observability by default**: OIDC-based CI/CD, gitleaks + Semgrep on every PR, structured logging and real alarms
- 🤖 I also build **UiPath RPA** automations, and I came from **civil engineering**, so I like systems that hold up under real load
- ☁️ Currently studying for **AWS Certified Cloud Practitioner**
